# Página pessoal — João Victor

Projeto da atividade prática de Fundamentos de Desenvolvimento de Software, feito com HTML, CSS e JavaScript, sem frameworks.

## Acessos

- [Abrir a página publicada](https://lasanhalala.github.io/pagina-pessoal-joao-victor/)
- [Ver o repositório no GitHub](https://github.com/lasanhalala/pagina-pessoal-joao-victor)

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `style.css`: estilos e adaptação para telas menores.
- `script.js`: interação do botão de mensagem.
- `assets/caminhada.svg`: ilustração de um dos hobbies.

O site é publicado pelo GitHub Pages a partir da pasta raiz da branch `main`.
